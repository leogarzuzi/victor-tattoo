# Victor Siena Art

Portfólio de tatuagem em HTML, CSS e JavaScript, com servidor local em Node.js.

## Rodar no computador

Instale o Node.js e o Git. No terminal, dentro desta pasta:

```powershell
npm.cmd run dev
```

Abra http://localhost:3000 e mantenha o terminal aberto.
Não é necessário instalar dependências do npm.

## Continuar em outro computador

Clone este repositório, abra sua pasta no editor e execute o comando acima.

Antes de começar a trabalhar em uma cópia existente:

```powershell
git pull
```

Para enviar as alterações ao GitHub:

```powershell
git add .
git commit -m "Descreva as alterações"
git push
```

## Arquivos principais

- `index.html`: composição, cabeçalho e estilos responsivos.
- `intro.js`: vídeo de abertura no desktop e entrada suave no mobile.
- `header.js`: menu de navegação e animação do ícone.
- `server.cjs`: servidor local na porta 3000.
- `assets/`: imagens, vídeos e fontes locais.
- `referencias-flow/`: referências visuais usadas na produção.

A licença da fonte Cinzel Decorative acompanha os arquivos em `assets/fonts/OFL.txt`.
